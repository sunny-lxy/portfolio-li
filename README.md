## 📖 简介

这是我的个人前端作品集网站，用于展示我学习前端开发过程中完成的多个项目。

网站采用**纯 HTML + CSS + JavaScript** 构建，整体风格**干净克制**，注重阅读体验与交互细节。

> 🔗 **在线访问**：[https://sunny-lxy.github.io/portfolio-li/](https://sunny-lxy.github.io/portfolio-li/)

---

## ✨ 核心功能

- **打字机效果**：Hero 区域标题逐字输出，展现动态美感
- **滚动触发动画**：元素进入视口时优雅淡入上移
- **卡片悬停交互**：项目卡片悬停上浮 + 阴影加深，反馈细腻
- **完全响应式**：完美适配手机、平板、桌面端
- **毛玻璃导航**：顶部导航栏带有毛玻璃吸顶效果
